# PAC-3310 Supplementary Cell Data

Supplementary cell-assay data, analysis notebooks, and OT-2 liquid-handler protocol locations for:

**PAC-3310: a selective M4 muscarinic receptor agonist that attenuates MK-801-induced hyperlocomotion in mice**

This repository follows the organization of the PAC-832 supplementary-data repository. It contains the cAMP and calcium-flux assays used to characterize PAC-3310 across M1–M5. Mouse behavioral data are maintained separately.

## Repository structure

```text
├── data/
│   ├── camp_assay/
│   │   ├── raw/             # Per-well fluorescence, plate standards, controls, and conditions
│   │   └── processed/       # Back-calculated cAMP values, summaries, and curve-fit results
│   └── ca_assay/
│       ├── raw/             # Per-replicate time-series fluorescence traces
│       └── processed/       # ΔF/F0 responses, transient fits, controls, and curve-fit results
├── notebooks/
│   ├── camp_analysis_consolidated.ipynb
│   ├── calcium_flux_analysis_consolidated.ipynb
│   └── functional_profile_figure.ipynb
└── ot2_protocols/
    ├── camp_assay/          # Six M2/M4 cAMP protocols
    └── ca_assay/            # Six M1/M3/M5 calcium-flux protocols
```

## Data

Each assay has `raw/` and `processed/` subdirectories. The public raw tables are canonical, analysis-ready exports, matching the convention used in the PAC-832 supplementary repository.

### cAMP assay

- M2 and M4 carbachol agonism, PAC-3310 agonism, and PAC-3310 antagonism plates are included.
- Antagonism used 20 nM carbachol for M2 and 100 nM carbachol for M4.
- Raw files contain well positions, fluorescence values, standards, controls, dose labels, and replicate assignments.
- The processed replicate table contains measured and 5× dilution-corrected real-sample cAMP concentrations in pmol/mL, normalized responses, and quality-control fields.
- Row-wise ELISA plate normalization from the source plate-reader workflow is retained.

### Calcium-flux assay

- M1, M3, and M5 carbachol agonism, PAC-3310 agonism, and PAC-3310 antagonism traces are included.
- Antagonism used 500 nM carbachol for M1, 100 nM for M3, and 500 nM for M5.
- Raw files contain time-series fluorescence traces for four replicate wells per concentration.
- Processed files contain bi-exponential transient-fit parameters, ΔF/F0 responses, control responses, and concentration-response fit statistics.

## Notebooks

The two consolidated assay notebooks contain the complete cAMP and calcium-flux analysis pipelines. Run them from the `notebooks/` directory. They read from the corresponding `data/*/raw/` folder, regenerate files in `data/*/processed/`, and create assay-specific figures in a local ignored `figures/` directory.

The separate `functional_profile_figure.ipynb` notebook reads the processed replicate-level outputs from both assays and reproduces the combined four-panel M1–M5 functional-profile figure (Figure 1 in the current report). This cross-assay figure cannot be generated by either assay notebook alone.

## OT-2 protocols

The 12 Opentrons OT-2 protocols are organized by assay under `ot2_protocols/`. The antagonism protocols identify the fixed carbachol concentration used for each receptor subtype.
