# Calcium-flux OT-2 protocols

Opentrons OT-2 protocols for the PAC-3310 calcium-flux experiments:

- `M1_Carbachol_and_PAC-3310_calcium.py`: M1 carbachol and PAC-3310 concentration responses.
- `M1_PAC-3310_plus_500nM_carbachol_calcium.py`: M1 PAC-3310 antagonism experiment with 500 nM carbachol.
- `M3_Carbachol_and_PAC-3310_calcium.py`: M3 carbachol and PAC-3310 concentration responses.
- `M3_PAC-3310_plus_100nM_carbachol_calcium.py`: M3 PAC-3310 antagonism experiment with 100 nM carbachol.
- `M5_Carbachol_and_PAC-3310_calcium.py`: M5 carbachol and PAC-3310 concentration responses.
- `M5_PAC-3310_plus_500nM_carbachol_calcium.py`: M5 PAC-3310 antagonism experiment with 500 nM carbachol.

All protocols target an OT-2 using Opentrons API level 2.20.
