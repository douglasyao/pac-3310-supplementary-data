# cAMP OT-2 protocols

Opentrons OT-2 protocols for the PAC-3310 cAMP experiments:

- `CHO-M2_carbachol_cAMP.py`: M2 carbachol concentration response.
- `CHO-M2_PAC-3310_cAMP.py`: M2 PAC-3310 concentration response.
- `CHO-M2_PAC-3310_plus_20nM_carbachol_cAMP.py`: M2 PAC-3310 antagonism experiment with 20 nM carbachol.
- `CHO-M4_carbachol_cAMP.py`: M4 carbachol concentration response.
- `CHO-M4_PAC-3310_cAMP.py`: M4 PAC-3310 concentration response.
- `CHO-M4_PAC-3310_plus_100nM_carbachol_cAMP.py`: M4 PAC-3310 antagonism experiment with 100 nM carbachol.

All protocols target an OT-2 using Opentrons API level 2.20.
